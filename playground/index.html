Identity for software agents.

One question governs every agent system: who authorized this, under what authority, and can you prove it three years later? agentid is a reference implementation that makes that question answerable — with signed delegations, hash-chained receipts, and a validation profile that travels with the decision.

The GDPR right to erasure, for agents

A subject requests deletion. The plan enumerates every receipt that touched their data, identifies the downstream systems and derived artifacts, and tracks a 30-day deadline — without the control plane ever holding the subject's personal data.

One content-addressed decision rule

Every receipt names the Validation Profile under which it was produced. Anyone can re-derive the decision from the inputs — no vendor trust required.

What it does

Signed human→agent delegations, scoped and expiring powers, budget-enforced constraints, approval thresholds, hash-chained receipts, an erasure plan for agent-collected data.

What it does not do

Stop prompt injection. Replace your security review. Claim NIST certification. Serve as an enforcement proxy in production today. Read the threat model first.

What it aligns with

NIST NCCoE agent identity direction, RFC 8693 delegation semantics, OAuth 2.1 as drafted, OpenTelemetry GenAI agent spans, and the emerging SP-1800 practice guide.
