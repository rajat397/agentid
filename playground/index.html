The system that actually ships

Five working layers, all in a Go 1.27 standard-library core. Everything below has a test, a CLI path and a document in the repository.

01 · ENVELOPE

Canonical action

A digest of action, system, resource, attributes is the unit of approval, validation and receipt. Seven typed predicates cover amounts, enumeration, windows, rolling sums, co-sign, equality and bounds.

constraints →
02 · PEP

MCP wrapper holds the key

The agent sees JSON-RPC tools, never credentials. Authority fields come from operator mapping, not tool arguments. Denials return -32000 with a receipt id and an approval request when applicable.

wrapper →
03 · DECISION

Deterministic & dual-signed

Deny-overrides across profiles, implicit deny, canonical obligation union. Delegations and receipts carry ES256 primary plus ML-DSA-65 post-quantum signatures; approvals must be signed by the approver.

combining →
04 · EVIDENCE

Bundle, anchors, telemetry

Signed receipts, status lists, customer-chosen anchors, five OTel spans and signer keys travel in one offline-verifiable bundle. A mismatch metric corroborates telemetry against receipts.

bundle →
05 · OPERATIONS

Lifecycle, not just issuance

SCIM deprovisioning revokes in bounded time; erasure executors emit deletion receipts; retention archives before pruning; control-plane policy bundles fail closed when stale.

Don't re-trust — re-derive

    
The decision, the evidence and the verification travel together. That is the entire point; the interface is incidental.

    
WHY NOW
NIST's NCCoE concept paper (February 2026) frames agent identity, authorization and audit for federal and critical-infrastructure use. SP 800-63-4 explicitly excludes agents; NISTIR 8587 names the risk. agentid is one runnable public answer — check the standards matrix and the threat model.
