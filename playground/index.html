02

Authority narrows as it delegates

A human grants an agent authority — a signed, expiring delegation with hard limits. If that agent delegates to another agent, every limit must narrow, never widen. Permissions intersect. Amount caps drop. Budgets shared across the chain are enforced at the point of action. This is not a policy you configure afterward — it is the data structure itself.

A
Attenuation is structuralA child grant with a wider cap than its parent cannot exist — it is rejected at creation. Not "advised against." Not "warned about." Rejected.
B
Caps are per action AND cumulativemax_amount caps a single call. sum_max draws down a shared budget across every call the chain makes, until it refuses.
C
Co-signature is an obligationAmounts above a threshold produce a cosign_above obligation. The relying party either discharges it with a human approval — or the action does not execute.
D
Decisions are re-derivableEvery receipt names the profile digest and the inputs. Any party can re-run the validation offline and get the same answer. No vendor trust required.

05

Evidence when you need to re-derive, not re-trust

Every decision this implementation makes is reproducible by any party holding the inputs. That property — not the interface — is the entire point of agent identity.

→
github.com/rajat397/agentidMIT-licensed. One dependency. 13 tests, all passing. Read the threat model before you deploy anything.
→
The Validation ProfileContent-addressed by SHA-256. Every receipt names it, so a decision can be re-derived offline.
→
What this is NOTProduction software. A NIST-certified artifact. A defense against prompt injection (out of layer — we bound impact). A claim that anything here is ratified by anyone.
